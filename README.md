This Python program implements a card game called "Pouilleux", where the player competes against the computer. The computer acts as the dealer, and the objective is to avoid ending up with the "Black Jack" (♣J).

Game Rules:
The deck of cards contains all standard playing cards except the Black Jack (♣J).
Players (Human and Computer) are dealt cards alternately until the deck is empty.
Players eliminate pairs of cards from their hands.
Players take turns drawing a card from the opponent’s hand and eliminating any new pairs.
The game ends when one player has no cards left:
The player with cards remaining loses.

Key Features:
Deck Preparation: A full deck is prepared, excluding the Black Jack.
Shuffling: The deck is shuffled randomly.
Pair Elimination: Pairs of cards are removed to simplify gameplay.
Interactive Gameplay:
Human players choose cards from the computer’s hand by position.
The computer picks a random card from the human’s hand.
Dynamic Feedback: The game provides real-time updates on hands and actions.
